# Clip+ focus shell v2 — handoff (2026-11-11)

## What this is

A redesign of the custom "focus" shell that runs on the Sansa Clip+ after the
Rockbox bootloader. Bootloader, drivers and codecs are untouched; only the
application UI under `work/rockbox-focus-fork/apps/` changed.

## State right now

- The new shell is **installed on Darren's player** (build `7daa82e9…`, 2026-11-11) together
  with the full codec set from the same build. The first v2 build (`ceb61a09…`) was
  booted and confirmed working by Darren, radio included.
- The later additions in the installed build — recorder, alarm editor, clock editor —
  are simulator-tested only. The simulator cannot record, so **recording still needs a
  real test**.
- Likely cause of the old "disk full" recording error: the player only had `mpa.codec`
  and `flac.codec`, so there was no encoder (`wav_enc.codec`). All 43 codecs are now
  installed.
- Backups of the player's `.rockbox` folder before each install are in
  `work/device-backups/` (not in git).

## Build

```sh
# assets (only after editing tools/focus_gen.py)
python3 tools/focus_gen.py work/rockbox-focus-fork

# player firmware
cd work/rockbox-focus-build && make -j8          # -> rockbox.sansa

# simulator (needs: brew install gcc sdl2)
cd work/rockbox-focus-sim && SDKROOT=$(xcrun --show-sdk-path) make -j8 && make install
```

Headless simulator test: put commands in `work/rockbox-focus-sim/simdisk/focus_script.txt`
(`k UP` tap, `h RIGHT 14` hold, `w 10` wait frames, `s name` screenshot to
`simdisk/shots/name.pgm`, `q` quit) and run
`SDL_VIDEODRIVER=dummy SDL_AUDIODRIVER=dummy ./rockboxui`.

## Controls

| Screen | Keys |
| --- | --- |
| Everywhere | Home = back, hold Home = lock/unlock, Vol +/- = volume, hold Power = off |
| Home / lists | Up/Down move, Select or Right opens, Left = back |
| Now Playing | Up or Select = play/pause, Left/Right = previous/next, hold Left/Right = seek (accelerates), Down or hold Select = options |
| Radio | Left/Right = previous/next station (or step when tuning by hand), hold Left/Right = seek to next station, Up = mute, Down = stations/tune mode, Select = menu, hold Select = save/remove station, Home = back with radio still playing |
| EQ | Left/Right = band, Up/Down = gain, Select = next preset |
| Recorder | Select = start / pause / resume, Home = save (then Home again to leave), Up/Down = mic gain. Records the radio if it is on, otherwise the microphone |
| Alarm / clock | Left/Right = field, Up/Down = change, Select = save, Home = cancel |

## Install (only with Darren's go-ahead)

The player must be in **MSC** USB mode (in MTP mode, product id 0x74D0, macOS cannot
mount it). Then:

1. Copy the player's `/.rockbox` folder to `work/device-backups/<date>/`.
2. Copy `work/rockbox-focus-build/rockbox.sansa` over `/.rockbox/rockbox.sansa` and
   `work/rockbox-focus-build/lib/rbcodec/codecs/*.codec` into `/.rockbox/codecs/`.
3. Eject, unplug, power on.

Rollback: boot the original SanDisk firmware (hold Left while powering on),
connect by USB and put the backed-up `rockbox.sansa` back.

## Hardware checklist after install

1. Boots to Home; icons and text readable; clock shown if the RTC is set.
2. Music: open a folder, play, pause, next/previous, hold to seek, Shuffle all.
3. Podcasts: play, power off mid-track, power on, Now Playing resumes.
4. **Radio (earphones in):** audio comes through; Left/Right step; hold seeks and
   stops on a station; Select > Auto scan fills Stations; save/remove a station;
   Home leaves radio playing; starting a track stops the radio; Radio off works.
5. EQ presets audibly change the sound; survives a reboot.
6. Hold Home locks and unlocks; volume keys; hold Power shuts down.
7. USB still mounts; after unplug the lists show new files.
8. Recordings > New recording: Select starts, Home saves, the file appears in the
   list and plays back. Try once with the radio on (records the radio).
9. Settings > Alarm and Set clock: editors save; header clock shows the new time.
